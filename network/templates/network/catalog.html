How photos are handled

  • Downloads go through the same SSRF-safe fetcher as the URL checker: https only, public addresses only, redirects re-checked, size and time limited. Private addresses are refused unless listed in LINKEDEYE_PROBE_ALLOWED_PRIVATE_CIDRS.
  • The bytes are checked, not trusted: PNG, JPEG and WebP only, decoded size read from the file header; SVG, GIF, animated images and files with anything appended are refused.
  • Photos are stored in the database (deduplicated by content) and served only to signed-in users, with fixed headers. The address they came from is recorded without any query string.
