Verify reachability

Nothing is probed until you press the button

LinkedEye checks each target now and reports DNS, the TCP port, whether an exporter answers on /metrics (and which one), whether the stored credential is accepted, and the host facts it found. For servers with an SSH credential it also logs in to read the hostname, OS, kernel, CPUs, memory and whether an exporter is already installed. All probing goes through the SSRF-guarded probe policy, and each SSH host key is pinned on first connect.
